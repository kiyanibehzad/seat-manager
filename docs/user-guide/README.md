# راهنمای تصویری فارسی Seat Manager و کنسول OpenAI

[دریافت راهنمای کامل (PDF، ۲۸ صفحه، ویرایش ۳)](seat-manager-training-fa.pdf)

بازبینی ۱۰ آبان ۱۴۰۵ (۱ نوامبر ۲۰۲۶) برای ChatGPT Business و روند دستی نسخهٔ `v0.1.0-beta.3` برنامه. عنوان‌های فهرست PDF قابل کلیک‌اند و پیوند «فهرست» در پایین صفحات، خواننده را به صفحهٔ ۲ برمی‌گرداند.

| موضوع | صفحه |
|---|---|
| پنل کارمند و مدیر، ثبت‌نام، کارهای روزانه، ظرفیت، ایمیل و اعلان | ۳ تا ۷ |
| کنسول جدید، اعضا و دعوت ایمیلی | ۸ و ۹ |
| تغییر سیت یک عضو و بررسی نتیجه | ۱۰ |
| ظرفیت و سقف ماهانهٔ پیش‌فرض Standard یا Premium | ۱۱ |
| ثبت درخواست سیت و تمدید | ۱۲ تا ۱۵ |
| انتقال Premium و حالت No Seat | ۱۶ تا ۱۸ |
| ثبت و تأیید درخواست کردیت، تنظیم سقف فردی و تکمیل پرونده | ۱۹ تا ۲۴ |
| سهمیهٔ پنج‌ساعته و هفتگی یک نفر در Seats | ۲۵ |
| گزارش توکن و کردیت همان کاربر در Codex & Work | ۲۶ |
| چک‌لیست روزانه و منابع | ۲۷ و ۲۸ |

برای تغییر سیت، در **Members** زبانهٔ **Users** و ستون **Seat type** را باز کنید. برای سقف اختصاصی، در **Billing** و زبانهٔ **Plan**، زیر **Monthly usage limits** به **Per user override** و **Manage** بروید. مثال راهنما از سقف قبلی ۱۰۰۰ و افزایش مصوب ۳۵۰ به سقف نهایی **۱۳۵۰ کردیت در ماه** می‌رسد. پس از ذخیره، سقف همان ایمیل را دوباره بررسی کنید و نتیجه را در برنامه ثبت کنید.

گزارش سهمیه با کلیک روی **Usage limits consumed** در ردیف عضو باز می‌شود. برای گزارش توکن و کردیت، در **Usage** زبانهٔ **Codex & Work** را انتخاب کنید و فیلتر **User** را روی همان حساب بگذارید. بازه و زمان به‌روزرسانی هر شاخص را هنگام مقایسه در نظر بگیرید.

عکس‌های کنسول فقط برش کنترل‌های عمومی هستند. تصویرهای برنامه و مثال‌ها دادهٔ ساختگی دارند. فونت وزیرمتن در PDF تعبیه شده است. راهنمای جاری در همین پوشه منتشر می‌شود.
